### Data Ownership / privacy expectations

In this privacy-preserving item location proximity proving service - the expectation is that:
1. A location commitment is published on chain that denotes the location of a deployed in-game structure (an SSU). This is the target coordinates - `target_location_commitment`. 
2. A server (operated by CCP - called `proof-generation`) knows the contents (`x,y,z` coordinates - `target_coordinates`) contained by the `target_location_commitment`.
3. The player and server both knows the player's current `x,y,z` coordinates (`player_coordinates`) and the player is allowed to request CCP's `proof-generation` server to generate a proof for them attesting to the fact that they're within _SOME_ proximity of the `target_coordinates`.
4. The on-chain Move contracts can verify the proofs generated by CCP's `proof-generation` server that proves (without revealing either `player_coordinates` NOR `target_coordinates` to the chain):
    - The two sets of `x,y,z` coordinates are within _SOME_ proximity of each other.
    - The proof was generated by CCP's `proof-generation` server (using a blinding factor - a private "secret" that only CCP's `proof-generation` server knows and can prove in a proof and verified on-chain without exposing the private secret)
